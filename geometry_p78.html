스스로 확인하기 & 수학으로 생각 넓히기 문제 풀이 (정사영)

01

정사영 찾기

정육면체에서 모서리 AE의 중점이 M일 때, 다음을 구하시오.
(1) 선분 BD의 평면 DHGC 위로의 정사영
(2) 삼각형 DMB의 평면 EFGH 위로의 정사영
선생님의 판서 풀이

  • (1) 선분 BD의 정사영

    점 B는 평면 DHGC에 수선을 내리면 점 C로 가고, 점 D는 평면 위의 점이므로 자기 자신(D)입니다.

    답: $\overline{DC}$

  • (2) $\triangle DMB$의 정사영

    각 꼭짓점을 밑면 EFGH로 수직으로 떨어뜨립니다.

    D $\rightarrow$ H, M $\rightarrow$ E, B $\rightarrow$ F

    답: $\triangle EFH$

02

선분의 정사영 길이

선분 AB의 평면 $\alpha$ 위로의 정사영이 선분 A'B'이고 이루는 각의 크기가 $\theta$일 때, 다음을 구하시오.
(1) $\overline{AB}=16, \theta=45^\circ$일 때, $\overline{A'B'}$의 길이
(2) $\overline{A'B'} = \frac{1}{2}\overline{AB}$일 때, $\theta$의 값
선생님의 판서 풀이

공식: $l' = l \cos\theta$

(1) $\overline{A'B'}$의 길이

$16 \times \cos 45^\circ = 16 \times \frac{\sqrt{2}}{2} = \mathbf{8\sqrt{2}}$

(2) $\theta$의 값

$\frac{1}{2}\overline{AB} = \overline{AB} \cos\theta \implies \cos\theta = \frac{1}{2}$

$\therefore \theta = 60^\circ$

03

평면의 정사영 넓이

모든 모서리의 길이가 같은 삼각기둥에서 점 M은 모서리 BE의 중점이다. 평면 ACM 위에 있는 반지름의 길이가 4인 원의 평면 DEF 위로의 정사영의 넓이를 구하시오.
선생님의 판서 풀이

두 평면이 이루는 각 $\theta$를 찾기 위해 삼각형 넓이 비를 이용합니다.

1) $\triangle ACM$ 넓이

모서리를 $a$라 하면, $\triangle ACM$의 높이 $\overline{MN}=a$ 입니다.

$S = \frac{1}{2} \times a \times a = \mathbf{\frac{1}{2}a^2}$

2) 정사영 $\triangle ABC$ 넓이

밑면 정삼각형이므로

$S' = \mathbf{\frac{\sqrt{3}}{4}a^2}$

$\frac{1}{2}a^2 \times \cos\theta = \frac{\sqrt{3}}{4}a^2 \implies \mathbf{\cos\theta = \frac{\sqrt{3}}{2}}$

반지름 4인 원의 넓이는 $16\pi$ 이므로, 정사영의 넓이 $S'$는

$S' = 16\pi \times \frac{\sqrt{3}}{2} = 8\sqrt{3}\pi$

04

정사면체 이면각의 비밀

오른쪽 그림과 같은 정사면체에서 모서리 AD의 중점을 M이라 하자. 두 평면 MBC, DBC가 이루는 각의 크기를 $\theta$라 할 때, $\cos\theta$의 값을 구하시오.
선생님의 판서 풀이

교선 BC에 내린 수선의 발을 N이라 하면, 이면각은 $\angle MND = \theta$ 입니다.

  • $\overline{MD} = \frac{a}{2}$ (모서리 절반)
  • $\overline{ND} = \frac{\sqrt{3}}{2}a$ (정삼각형의 높이)
  • $\overline{MN} = \frac{\sqrt{2}}{2}a$ (이등변삼각형 MBC의 높이)

💡 직각삼각형 발견

$\overline{MD}^2 + \overline{MN}^2 = \frac{a^2}{4} + \frac{2a^2}{4} = \frac{3a^2}{4} = \overline{ND}^2$ 가 성립합니다.

즉, $\triangle DMN$은 $\angle DMN = 90^\circ$인 직각삼각형입니다!

직각삼각형이므로 코사인 값은 빗변 분의 밑변으로 바로 나옵니다.

$\cos\theta = \frac{\overline{MN}}{\overline{ND}} = \frac{\frac{\sqrt{2}}{2}a}{\frac{\sqrt{3}}{2}a} = \frac{\sqrt{6}}{3}$

수학으로 생각 넓히기

기울어진 물기둥과 정사영

밑면 반지름 길이가 4cm, 높이가 9cm인 원기둥 모양의 그릇에 높이가 6cm가 되도록 물을 채운 후 물이 흘러내리기 직전까지 기울였다.
(1) 기울인 그릇의 밑면과 지면이 이루는 각의 크기를 $\theta$라 할 때, $\cos\theta$ 의 값을 구하시오.
(2) 기울인 그릇의 수면의 넓이를 구하시오.
선생님의 판서 풀이

(1) $\cos\theta$ 의 값 구하기

흘러내리기 직전이므로 가장 높은 수면은 높이 9에 닿아 있고, 빈 공간의 직각삼각형 ABC를 그립니다.

밑면 지름 $\overline{BC} = 8$ 이고, 물기둥의 수위 차이 $\overline{AB} = 9 - 3 = 6$ 입니다. (판서 기준 $\overline{AB}=6$)

피타고라스 정리: $\overline{AC} = \sqrt{8^2 + 6^2} = 10$

$\cos\theta = \frac{\overline{BC}}{\overline{AC}} = \frac{8}{10} = \mathbf{\frac{4}{5}}$

(2) 수면의 넓이 구하기

타원 모양의 수면 넓이를 $S$라 하면, 이것을 지면에 정사영시킨 넓이는 반지름이 4인 원래 그릇의 밑면 넓이($16\pi$)와 같습니다.

$S \times \cos\theta = 16\pi \implies S \times \frac{4}{5} = 16\pi$

$\therefore S = 20\pi$
