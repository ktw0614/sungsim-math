01

정팔면체의 모서리 위치 관계

오른쪽 그림과 같은 정팔면체에서 모서리 AB와 꼬인 위치에 있는 모서리의 개수를 $a$, 평행한 모서리의 개수를 $b$라 할 때, $a+b$의 값은?
선생님의 판서 풀이

1) 꼬인 위치 ($a$)

모서리 AB와 만나지도 않고 평행하지도 않은 모서리는 $CD, CF, DE, EF$ 입니다.

$\therefore a = 4$

2) 평행한 모서리 ($b$)

모서리 AB와 평행한 모서리는 마주보는 $DF$ 하나 뿐입니다.

$\therefore b = 1$

답: $a + b = 5$

2) 평행한 모서리 ($b$)

모서리 AB와 평행한 모서리는 마주보는 $DE$ 하나 뿐입니다.

$\therefore b = 1$

답: $a + b = 5$

02

꼬인 두 직선이 이루는 각

오른쪽 그림과 같은 정삼각기둥에서 직선 AB와 직선 EF가 이루는 각의 크기는?
선생님의 판서 풀이

꼬인 위치에 있는 두 직선의 각을 구하기 위해 한 직선을 평행이동합니다.

직선 $EF$를 윗면으로 평행이동하면 직선 $BC$가 됩니다.

따라서 직선 $AB$와 직선 $EF$가 이루는 각은 $\angle ABC$ 와 같습니다.

$\triangle ABC$는 정삼각형이므로 내각은 $60^\circ$ 입니다.

답: $60^\circ$

03

정육면체와 두 직선이 이루는 각

정육면체 선분 AB 중점 M. 직선 MF와 DH가 이루는 각 $\alpha$, 직선 MF와 GH가 이루는 각 $\beta$라 할 때, $\cos\alpha \times \cos\beta$ 의 값은?
선생님의 판서 풀이

모서리 길이를 $a$라 하면, $\overline{BF} = a$, $\overline{MB} = \frac{a}{2}$ 입니다.

피타고라스 정리: $\overline{MF} = \sqrt{a^2 + \left(\frac{a}{2}\right)^2} = \frac{\sqrt{5}}{2}a$

1) $\cos\alpha$ 구하기

직선 DH를 평행이동하면 BF입니다. 즉, $\alpha = \angle MFB$.

$\cos\alpha = \frac{\overline{BF}}{\overline{MF}} = \frac{a}{\frac{\sqrt{5}}{2}a} = \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}$

2) $\cos\beta$ 구하기

직선 GH를 평행이동하면 AB입니다. 즉, $\beta = \angle FMB$.

$\cos\beta = \frac{\overline{MB}}{\overline{MF}} = \frac{a/2}{\frac{\sqrt{5}}{2}a} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$

답: $\frac{2\sqrt{5}}{5} \times \frac{\sqrt{5}}{5} = \frac{2}{5}$

04

삼수선 정리의 연속 적용

평면 $\alpha$ 밖의 점 P에서 내린 수선의 발 H, H에서 선분 AB에 내린 수선의 발 R. $\overline{PH}=\sqrt{11}, \overline{AR}=8, \overline{AP}=10$ 일 때, $\overline{PR}+\overline{HR}$ 의 값은?
선생님의 판서 풀이

삼수선 정리에 의해 $\overline{PR} \perp \overline{AB}$ 이므로 $\triangle PRA$는 직각삼각형입니다.

$\overline{PO} \perp \alpha$ 이므로 $\triangle PHR$도 $\angle PHR=90^\circ$인 직각삼각형, $\triangle PHA$도 $\angle PHA=90^\circ$인 직각삼각형입니다.

1) 직각삼각형 PRA에서: $\overline{PR} = \sqrt{10^2 - 8^2} = \sqrt{36} = \mathbf{6}$

2) 직각삼각형 PHR에서: $\overline{HR} = \sqrt{\overline{PR}^2 - \overline{PH}^2} = \sqrt{36 - 11} = \sqrt{25} = \mathbf{5}$

* 판서에는 $\overline{AH} = \sqrt{100-11}=\sqrt{89}$ 를 먼저 구하고, 직각삼각형 AHR에서 $\overline{HR} = \sqrt{89-64}=5$ 로 구하는 방법도 제시되어 있습니다.

답: $\overline{PR} + \overline{HR} = 6 + 5 = 11$

05

삼각기둥에서의 수선과 넓이

삼각기둥에서 $\overline{AB}=1, \overline{AC}=\sqrt{2}, \overline{BE}=3, \angle BAC=90^\circ$. 점 A에서 EF에 내린 수선의 발을 H라 할 때, $\overline{AD} \times \overline{AH}^2$ 의 값은?
선생님의 판서 풀이

$\overline{AD} = \overline{BE} = 3$ 입니다. 점 D에서 선분 EF에 내린 수선의 발이 동일하게 H가 됩니다. (삼수선 정리)

직각삼각형 $\triangle DEF$ 넓이를 두 가지 방법으로 구합니다. ($\overline{DE}=1, \overline{DF}=\sqrt{2}, \overline{EF}=\sqrt{3}$)

$S = \frac{1}{2} \times 1 \times \sqrt{2} = \frac{1}{2} \times \sqrt{3} \times \overline{DH} \implies \mathbf{\overline{DH} = \frac{\sqrt{6}}{3}}$

직각삼각형 $\triangle ADH$ 에서 피타고라스 정리를 적용합니다.

$\overline{AH}^2 = \overline{AD}^2 + \overline{DH}^2 = 3^2 + \left(\frac{\sqrt{6}}{3}\right)^2 = 9 + \frac{6}{9} = 9 + \frac{2}{3} = \mathbf{\frac{29}{3}}$

답: $\overline{AD} \times \overline{AH}^2 = 3 \times \frac{29}{3} = 29$

06

직육면체의 이면각과 수직

직육면체에서 $\overline{AB}=\overline{AD}=2$ 이다. 평면 AFH와 평면 CHF의 이면각의 크기가 $90^\circ$일 때, 선분 AE의 길이를 구하시오.
선생님의 판서 풀이

대각선 FH의 중점을 M이라 하면, $\triangle AFH$와 $\triangle CFH$는 모두 이등변삼각형입니다.

($\because \overline{AF}=\overline{AH}=\overline{CF}=\overline{CH} = \sqrt{2^2+\overline{AE}^2}$ 이므로 합동)

이면각이 $90^\circ$라는 것은, 교선 FH에 각각 내린 수선 AM과 CM이 이루는 각이 $90^\circ$임을 의미합니다.

즉, $\angle AMC = 90^\circ$ 이므로 $\triangle AMC$는 직각이등변삼각형입니다.

$\overline{AC} = 2\sqrt{2}$ 이고, $\triangle AMC$에서 피타고라스 정리에 의해
$\overline{AM}^2 + \overline{CM}^2 = 2\overline{AM}^2 = (2\sqrt{2})^2 = 8 \implies \overline{AM}^2 = 4 \implies \mathbf{\overline{AM} = 2}$

이제 직각삼각형 $\triangle AEM$을 생각합니다. (수선의 발 E)

밑면 대각선 절반 $\overline{EM} = \frac{1}{2} \times 2\sqrt{2} = \sqrt{2}$ 입니다.

$\overline{AE} = \sqrt{\overline{AM}^2 - \overline{EM}^2} = \sqrt{4 - (\sqrt{2})^2} = \sqrt{2}$

$\therefore \overline{AE} = \sqrt{2}$
