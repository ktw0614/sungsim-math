1. 개념 시각화 랩

복잡한 기하학적 정의를 애니메이션으로 직관적으로 이해합니다.
📈

이차곡선 정의 시각화 도구

포물선, 타원, 쌍곡선의 기하학적 정의(거리의 합/차 등)를 슬라이더를 통해 움직이며 실시간으로 확인해 봅니다.
✍️

2. 실전 훈련 랩

방정식을 유도하고 평행이동을 적용하는 훈련을 무한 반복합니다.
🧩

방정식 유도 단계별 훈련

타원과 쌍곡선의 초점, 거리의 합/차를 이용해 a², b² 값을 찾고 방정식을 완성하는 4단계 빌드업 과정을 연습합니다.

무한 문제 생성 지원
♾️

평행이동 실전 무한 훈련기
