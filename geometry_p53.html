25

타원과 포물선의 교점

두 점 $A(5, 0), B(-5, 0)$에 대하여 장축이 $\overline{AB}$인 타원의 두 초점을 각각 $F, F'$이라 하자. 초점이 $F$이고 꼭짓점이 원점인 포물선이 타원과 만나는 두 점을 각각 $P, Q$라 하고 $\overline{PQ}=8$일 때, $\overline{PF'} - \overline{PF}$의 값을 구하시오.
(단, 점 $F$의 $x$좌표는 양수이다.)
선생님의 판서 풀이

타원의 장축이 $\overline{AB}$ 이고 $A(5,0), B(-5,0)$ 이므로 중심은 원점입니다.

타원의 초점이 $F(c, 0)$ 이므로, 다른 초점 $F'$은 $(-c, 0)$ 입니다. (단, $c>0$)

1) 미지수 설정 및 타원의 정의

$\overline{PF'} = m$, $\overline{PF} = n$ 이라 합시다.

타원의 정의(거리의 합=장축): $m + n = 10$

2) 포물선의 정의와 직각삼각형 발견

포물선의 꼭짓점이 원점, 초점이 $F(c,0)$ 이므로 준선은 $x=-c$ 입니다.

★ 즉, 타원의 다른 초점 $F'(-c, 0)$은 정확히 포물선의 준선 위에 위치합니다!

점 P에서 준선에 내린 수선의 발을 $H$라 하면, 포물선의 정의에 의해 $\overline{PF} = \overline{PH} = n$ 입니다.

직각삼각형 $\triangle PF'H$에서 점 $P$에서 $x$축에 내린 수선의 발을 $M$이라 할 때, 대칭성에 의해 $\overline{PM} = 4$ 이므로 $\overline{F'H} = \overline{PM} = 4$ 입니다.

피타고라스 정리에 의해 $4^2 + n^2 = m^2$ 가 성립합니다.

$m^2 - n^2 = 16$

합차 공식 $(m-n)(m+n) = 16$ 에 $m+n=10$ 을 대입하면,
$10(m-n) = 16 \implies m-n = \frac{16}{10} = \frac{8}{5}$

$\therefore \overline{PF'} - \overline{PF} = \frac{8}{5}$

쌍곡선과 삼각형의 둘레

쌍곡선 $\frac{x^2}{9} - \frac{y^2}{7} = 1$ 위의 점 $P$와 두 초점 $F, F'$에 대하여 삼각형 $PFF'$의 둘레의 길이가 $24$일 때, $\overline{PF'}^2 - \overline{PF}^2$의 값을 구하시오.
(단, 점 $P$는 제1사분면에 있고 점 $F$의 $x$좌표는 양수이다.)
선생님의 판서 풀이

초점 구하기:

$a^2 = 9, b^2 = 7 \implies c^2 = 16 \implies c = 4$

$\therefore \overline{FF'} = 8$

삼각형의 둘레의 길이가 24이므로,

$\overline{PF'} + \overline{PF} + \overline{FF'} = 24$

$\implies \overline{PF'} + \overline{PF} = 16$

쌍곡선의 정의에 의해 거리의 차는 주축의 길이($2a$)와 같습니다.

$\implies \overline{PF'} - \overline{PF} = 2 \times 3 = 6$

구하고자 하는 값은 합차 공식을 이용합니다.

$\overline{PF'}^2 - \overline{PF}^2 = (\overline{PF'} - \overline{PF})(\overline{PF'} + \overline{PF})$

$\therefore 6 \times 16 = 96$
