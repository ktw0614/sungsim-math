1

기본 뼈대(Template) 파일 복사 및 준비

바탕화면에 새 텍스트 문서(메모장)를 열고, 아래 버튼을 눌러 뼈대 코드를 통째로 붙여넣으세요.

선생님이 미리 환경을 모두 세팅해 둔 무결점 HTML 뼈대 코드입니다.
아래 버튼을 눌러 복사한 뒤, 빈 메모장에 [Ctrl+V] 하세요!

2

뼈대 코드 안에 AI 코드 조립하기 (결합)

메모장에 붙여넣은 뼈대 코드 중간에 있는 '주석 경고등(🚨)' 사이 빈칸에 AI 코드를 복붙하세요.

3

메모장 '다른 이름으로 저장' 3대 수칙

코드를 결합한 후 [파일] ➔ [다른 이름으로 저장]을 누르고 아래 3가지를 반드시 지키세요.

💾

1. 파일 이름 (확장자)

.html

이름 끝에 직접 .html을 타이핑해야 웹페이지로 인식됩니다.

📁

2. 파일 형식

모든 파일 (*.*)

'텍스트 문서'로 두면 .html.txt가 되어 브라우저에서 안 열립니다.

🌐

3. 인코딩

UTF-8

한글(수식 설명, 제목 등)이 외계어로 깨지는 현상을 방지합니다.

4

최종 제출 규칙 (반드시 확인)

모든 테스트를 통과했다면 지정된 양식에 맞게 파일을 변경하여 제출합니다.
